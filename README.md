# Automatic Patient Management System (APMS)

## Description
The Automatic Patient Management System is a Python application used to manage patient records, appointments, and hospital information.

## Features
- Patient Registration
- Appointment Booking
- View Patient Records
- Search Patient
- Update Patient Details
- Delete Patient Records

## Technologies Used
- Python
- CSV File

## How to Run
1. Install Python.
2. Open the project folder.
3. Run:
   python main.py
